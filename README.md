### Projects

**[worldcup-halftime-analysis](https://github.com/rasxim/worldcup-halftime-analysis)** — Python, pandas, SciPy, matplotlib

Does the first half decide a World Cup match? 836 matches reshaped into 1,672
team-match records to fix a conditional probability that is usually computed
backwards. Teams leading at half-time win 80.3% of matches; teams trailing win
8.3%. Wilson score intervals, chi-square and Fisher exact tests, 11 unit tests.

**[transport-network-simulation](https://github.com/rasxim/transport-network-simulation)** — Java

Discrete-time freight simulation built on four generic collections written from
scratch, with no `java.util` collections anywhere: a stack for LIFO cargo, FIFO
queues for warehouse docks, and a re-sortable priority manifest whose sort key
changes as the truck moves. 73 unit tests.
